# Beat 中文版 · 使用手册

**一句话**：把一部片子的想法、剧本、人物、画面、分镜、拍摄日全部摊在一块无限大的画布上，最后导出成能给任何人看的文件。

界面已经全中文。**设置 `⌘ ,` → 最上方「Language / 界面语言」** 随时切回 English，不用重启。

---

## 0. 三步上手

| 步骤 | 做什么 | 怎么做 |
| --- | --- | --- |
| 1 | 建项目 | 打开 Beat → 选模板（推荐「三幕结构」）→ 起个名字 |
| 2 | 摆卡片 | 双击空白画布＝新建一张「节拍卡」；左边 `＋`＝加别的卡片 |
| 3 | 导出 | 顶栏 **导出** → 选格式 → 导出 |

就这三步。下面每章都只是为了把这三步做细。

---

## 1. 五分钟做出第一个项目

1. **打开 Beat**：启动后是「项目」窗口，列出你所有片子。点 **新建项目**。
2. **选模板**：
   - 空白画布 —— 什么结构都不要，自己摆
   - 三幕结构 / 英雄之旅 / 十五节拍 / 皮克斯故事脊柱 / 丹·哈蒙故事圆 —— 经典叙事骨架，卡片已经摆好
   - 提案文档（分节）—— 直接冲「Treatment」去的
   - 制作时间线 / 参考板 —— 前期制作与视觉参考
3. **双击画布空白处**：出现一张节拍卡（Beat）。直接打字，写这一场/这一拍发生什么。
4. **拖卡片**：随便挪，画布无限大。滚轮/双指滑动平移，捏合或 `Ctrl + 滚轮` 缩放。
5. **`⌘ 0`**：一键把全部内容装进屏幕。
6. **`⌘ S`**：保存（平时也在自动存，这键是手动确认一次）。
7. 想换视角：`⌘ ⇧ W` 进**写作模式**，同样的内容变成连贯文稿，从头读到尾。

> 记不住快捷键没关系：`⌘ K` 打开**命令面板**，输入「导出」「写作」「人物」就能直接跳过去执行。

## 2. 界面地图

界面只有三块：**顶栏**（功能入口）、**左侧竖排工具条**（元件与视图）、**中间无限画布**（内容）。右下角常年挂一个全图小地图，其余全是浮层，按一下出现、`Esc` 收起。

**顶栏（从左到右）**

| 按钮 | 干什么 |
| --- | --- |
| 保存 | 立即保存 + 刷新项目缩略图（`⌘ S`） |
| 项目信息 | 片名、署名、主题配色、背景设定（`⌘ I`） |
| 大纲 | 全部标题/分组的树状目录，点一下飞过去 |
| 写作 | 进入写作模式，把卡片读成文稿（`⌘ ⇧ W`） |
| 拍摄日 | 把分镜当拍摄日跑（On set） |
| 导出 | 导出中心，15 种格式（见第 5 章） |
| 项目 / 筛选 / 检查器 | 切换项目、按条件筛卡片、打开右侧详情（`I`） |
| ⋯ | 版本历史、地点地图、演示、带我逛逛、快捷键、设置、换库文件夹、撤销/重做 |

**左侧工具条（从上到下）**

| 图标 | 干什么 |
| --- | --- |
| `＋` | 添加卡片（第 3 章的五组） |
| 章节 | 跳到任意标题或分组 |
| 清屏卡片 | 隐藏空字段和按钮，只在鼠标悬停时露出来（画面瞬间干净） |
| 音频 | 音频时间轴（拖一个音频文件进画布就进来） |
| 素材库 / 人物 | 图片仓库 / 人物·地点·道具清单 |
| 适应 | 全部内容装进屏幕（`⌘ 0`） |
| 小地图 | 右下角全图导航 |

## 3. 卡片：把想法摆上桌

左边 `＋` 里有五组，共 17 种卡。**不用记全，记住每组干什么就够。**

| 组 | 卡片 | 用来做什么 |
| --- | --- | --- |
| **故事** | 节拍 Beat | 一个情节点、一场戏、一句台词。**最常用，占 90%** |
| | 标题 Title | 章节/幕的标题，大纲树靠它分节 |
| | 备注 Note | 提醒自己或组员的事，不算剧情 |
| | 想法 Thought | 还没定的脑洞，先扔上去 |
| **人物·地点** | 人物 Character | 角色档案：照片、性格、经历 |
| | 地点 Location | 场景档案，能挂经纬度算日照 |
| | 道具 Prop | 关键物件，带数量和勾选 |
| **视觉** | 图集 Gallery | 一组参考图 |
| | 手绘 Sketch | 直接在卡上画 |
| | 参考图 Reference | 单张大图 |
| | 配色 Palette | 片子的色彩方案 |
| **制作** | 分镜表 Shot list | 场次 + 镜头，带机位/镜头/时长/备注 |
| | 场地平面 Set Plan | 俯视图上摆机位和演员走位 |
| | 清单 Checklist | 器材、道具、待办 |
| **附件** | 文档 / 导入剧本 / 链接 / 导入视频 / 视频链接 | 把外部东西挂进片子 |

**四件事让卡片活起来**

- **`@` 提及**：在节拍正文里打 `@`，选人物/地点/道具 → 卡片之间自动建立联系，人物库会统计他出现在哪些场。
- **连线**：把卡片边缘的小圆点拖到另一张卡上＝因果线。点中连线可按 Delete 删掉，右键改颜色/线型/标签。
- **多选**：`Shift + 点`；`Shift + 拖` 框选；选中后「链接」按钮可把几张卡绑成一组一起移动。
- **粘贴即入**：图片、网址、文本直接 `⌘ V` 到画布，会自动变成参考图 / 链接卡 / 备注。

## 4. 六个视图，一套内容

同一份内容，六种看法。右上角视图随时互切，**不用复制粘贴**。

### 4.1 画布（默认）
摆卡片、连线、看全局。适合「想结构」。

### 4.2 写作模式 `⌘ ⇧ W`
把卡片按顺序读成一篇连续文稿。
- **聚焦**：只亮当前段落，其余变暗，专治写不进去
- **纸张**：跟界面主题，或强制浅色/深色纸
- **新条目**：一次粘贴一整段大纲，每行标成「镜头 / 道具 / 备注」自动变成卡片
- 行内 `⌘ 1..9` 给当前行打标签

### 4.3 大纲
树状目录：标题 → 分组 → 卡片。点一下飞过去。适合「查漏」。

### 4.4 分镜（时间轴）
顶栏 **分镜** 按钮（打开一个分镜表后出现）。
- 横轴＝时间，卡片宽度＝镜头时长，按场分泳道
- **拖动卡片**＝改拍摄顺序（同场重排或跨场移动）
- **按住卡片左右滑**＝预览该镜头
- **点卡片**＝飞回画布对应位置并打开详情
- 顶部可切「故事顺序 / 拍摄顺序」、缩放、只看未拍、导出分镜表

### 4.5 拍摄日 On set
把分镜表当一天来跑，全屏大字，现场用。
- **▶ 开始今天**：开始计时；**收工**：冻住时钟、出报告、剩下的顺延
- 键盘：`空格`＝拍一条 · `1–9`＝选第几条 · `d`＝完成 · `s`＝跳过 · `↑↓`＝调整顺序
- 右上 `A− / A+` 调字号（现场离屏幕远也能看清）
- 收工时按「日报告」出一份 PDF

### 4.6 摄像机（运镜与镜头切换）

打开一个**镜头表**后，顶栏「分镜」旁边会出现 **摄像机**。左边是按场分组的镜头序列，中间是取景框实时预览，右边只放这个镜头用得上的两个参数。

**运镜**（镜头内部摄像机怎么动）：固定 / 推 / 拉 / 摇 / 俯仰 / 横移 / 纵深移 / 升降 / 手持 / 环绕，各带一个 **强度** 0.2–3×，决定动多快、幅度多大。

**切换**（这个镜头怎么接上一个）：切 / 叠化 / 划像 / 淡入淡出，各带 **时长** 0–3 秒。第一个镜头没有入镜转场。

| 操作 | 作用 |
| --- | --- |
| 左栏点镜头 | 跳到这个镜头 |
| `空格` | 按顺序播放整场 —— 运动会真的走一遍，转场也会真的过一遍，用来判断节奏 |
| `← →` | 上一个 / 下一个镜头 |
| `Esc` | 关闭 |

设置**存在镜头卡本身**（`camMove` / `camSpeed` / `transition`），不动数据结构，跟着项目走、跟着同步走。没设过的镜头按「固定 + 切」显示，不会影响老项目。

用法上最省事的顺序：先把镜头表和时长填个大概 → 在摄像机里逐镜挑运镜 → 点空格连着看一遍 → 哪里拖沓就回去剪时长。

### 4.7 素材库（人物·地点·道具）
- 分三个页签，每张卡显示头像、名字、出场场次数
- 点开是完整档案：照片条、事实区、描述、被哪些节拍提到、连线、站位
- 顶部提示「还没用在任何地方的」元素，避免白建

## 5. 出片：导出怎么选

顶栏 **导出** 打开导出中心：左边选格式，中间实时预览真实排版，右边只有该格式真正有用的选项。**上次选的格式会记住。**

| 你想干什么 | 选这个 |
| --- | --- |
| 给投资人/客户看整片概览 | **项目概览（PDF）** |
| 交一份正式提案文档，一节一页 | **Treatment（PDF）** |
| 把画布原样印成 PDF | **画布 → PDF（打印版式）** |
| 画分镜给人看 | **分镜图（Storyboard，PDF）** |
| 路演 16:9 大屏 | **提案演示（Pitch deck，PDF）** |
| 给编剧/改稿人 | **Word — 干净版 / 批注版（.docx）** |
| 给制片主任排期 | **镜头表（PDF / CSV）** |
| 给制片拆解预算 | **拆解表（PDF）** |
| 给器材组 | **器材汇总（PDF）** |
| 进 Final Draft 等编剧软件 | **剧本脚手架（.fountain）** |
| 让 AI 接着写 | **给 AI 对话用（.md）** |
| 打包所有图片视频 | **导出全部素材（.zip）** |

**通用选项**：封面要不要放项目身份、只导已标记的项还是全部、纸张大小。
**署名**：设置 → 「导出上的署名」，会出现在封面；单个项目也能在「项目信息」里关掉。

**关于中文**：界面语言是中文时，导出的固定标题、页眉、表头、栏目名都是中文，你写的内容按原文输出。
PDF 里的中文是用系统字体**渲染成图片**贴进去的（这样不必往 PDF 里塞字体文件），所以 PDF 里的中文**不能被选中复制**；
需要可选中的中文长文档，用 **画布 → PDF（打印版式）** 走系统打印另存。Word / CSV / Markdown / Fountain 不受影响，文本照样可选。

## 6. 让 AI 一起干活

两条路，按需要选。

### 6.1 导出给 AI 看（最简单，不用配置）

导出 → **给 AI 对话用（.md）** → 把文件内容整段粘进任何 AI 对话（Claude、ChatGPT、本地模型都行）。

它拿到的是一份完整项目说明：梗概、人物、场景、分镜。适合问「第三幕哪里塌了」「帮我把这版改成喜剧调」。

### 6.2 让 AI 直接改项目（MCP 连接）

菜单/关于里的 **Link to Claude** → 勾「Enable」→ 点 **Link now**（Beat 自动写配置），或手动把下面这段并进 `claude_desktop_config.json`：

```json
{"mcpServers": {"beat": {"command": "beat-connector", "args": ["--library", "/Users/你的用户名/Documents/Beat Projects"]}}}
```

重启 Claude Desktop 或 Claude Code 即生效。之后直接说「打开 nes 这个项目，把第二场拆成三个镜头」，它改的是你的项目文件，画布一两秒内跟着变。

- 它**只能新增和修改，不能删除**；每次改动都留快照，版本历史可回滚
- 项目始终是你 Mac 上的文件，不往任何服务器上传
- 要用 **Claude Desktop 或 Claude Code**，网页版够不到本地工具
- 没有 Claude 也能用 6.1 那条路，功能不会少

## 7. 中英切换

- **设置 `⌘ ,` → 最上方「Language / 界面语言」→ English / 简体中文**，立刻生效，不用重启。
- 语言包是独立文件，放在你的库文件夹 `.beat-lang/zh-CN.json`，可以自己改词条（改完重开生效）。
- 原生菜单（文件/编辑/视图…）跟着界面语言一起变。
- 每个项目、每台 Mac 各自记语言，互不影响。

## 9. 文件、备份、常见问题

**项目存在哪**
所有项目都在一个「库文件夹」里，默认 `~/Documents/Beat Projects`。设置 → 库 可以换。
把这个文件夹放进 iCloud Drive，两台 Mac 就能共用同一批片子 —— **同一时间只在一台机器上打开**，否则 iCloud 会挑一个版本留下。

**会自动保存吗**
会，一直在后台存。`⌘ S` 是"手动再确认一次 + 刷新缩略图"。另有版本历史（`⋯ → 版本历史`）可以回退。

**换电脑 / 重装**
拷走库文件夹就行。整个片子（含图片、音频、分镜）都在里面。

**界面还有英文怎么办**
语言包在 `.beat-lang/zh-CN.json`，就是一张「英文原文 → 中文」的对照表：

```json
{"Shot list": "镜头表", "Duration": "时长", "Start day": "开始今天"}
```

缺一条补一条，注意英文原文要**一字不差**（含标点、省略号、首尾空格），逗号别丢，保存后重启 Beat 生效。

**导出是中文吗**
是。固定标题、页眉、表头、栏目名跟着界面语言走；你写的内容按原文输出。
PDF 里的中文是渲染成图片贴进去的，不可选中复制 —— 要可选中的中文用「画布 → PDF（打印版式）」另存。

**快捷键没反应**
先看是不是在输入框里（文字框内快捷键会失效，这是故意的）。画布上的单键（`I`、`?`）在写作模式里不生效。

**画面太乱**
左侧「清屏卡片」按一下，空字段和按钮全部收起，只留内容。
